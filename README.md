# scrp.nexus.app
SCRP Nexus — твій кіберпанк-термінал для контролю фінансів. Кросплатформений вебзастосунок та бот (@SCRP_Nexus_bot) для обліку доходів і витрат. Швидкі кнопки, AI-аналітика, фото чеків, нагадування про кредити та зручна адмін-панель. Візьми свої гроші під жорсткий контроль у стилі темного сай-фай!
